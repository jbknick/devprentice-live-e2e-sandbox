# Contributing to this test fixture

This repository exists only for Devprentice end-to-end tests. It is not a real open-source program.

Use a uniquely named test branch. Keep changes bounded to fixture documentation or fixtures/contribution.json. Open a pull request against main, describe the test run, and wait for the maintainer to review it. The required sandbox workflow must pass before merge.

Do not include secrets, production credentials, personal data, or real project work. Keep unsubmitted work on your branch so it can be resumed. Close test pull requests after the run unless the run explicitly verifies merging.

Ask for help through the test pull request. AI assistance is allowed with disclosure; the contributor remains responsible for reviewing and validating the change.
